SOC detection lab · Linux sshd + Windows Security events

Find brute force and password spraying in auth logs

Paste a Linux auth.log or Windows Security events (4624, 4625, 4740) as JSON. Four YAML detection rules run over the events, and each alert gets a MITRE ATT&CK technique, evidence lines, triage steps and an escalation note.

How it works

    

      
1 · Parse
sshd Failed … / Accepted … lines (syslog or RFC 3339 timestamps) and Windows events 4624, 4625, 4740 (flat or nested JSON) become one event format. PAM duplicate lines are ignored so one attempt counts once.

      
2 · Detect
Sliding-window rules from rules/default.yaml: AS-001 brute force (5 fails, same IP + account, 5 min) · AS-002 password spraying (4 accounts from one IP, 10 min) · AS-003 success after 3+ failures (10 min) · AS-004 lockout burst (3 lockouts on a host, 15 min).

      
3 · Report
Each alert becomes an incident with severity, ATT&CK technique (T1110.001, T1110.003, T1078, T1110), up to 10 evidence lines, triage steps and an escalation note.
